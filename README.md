# IndiCo Naturals — Groundnut Oil Website

React + Vite website redesigned from **Presentation1.pptx** content and brand images.

## Brand

- **IndiCo Naturals** (product line)
- **IndiCo Global** (export company)
- Tagline: *Connecting India to the World*

## Products

| Route | Product |
|-------|---------|
| `/products/cold-press` | Cold-Pressed Groundnut Oil |
| `/products/refined` | Refined Groundnut Oil |

## Pages

| Route | Content from PPT |
|-------|------------------|
| `/` | Hero, commitment, features, products, export, advantages |
| `/products` | Product listing |
| `/products/cold-press` | Specs, applications, nutrition (slides 8–14) |
| `/products/refined` | Specs, applications, nutrition (slides 15–20) |
| `/quality` | Certifications, lab validation, 3-step QC (slides 22–26) |
| `/about` | Company story, foundation, expertise, evolution (slides 12, 31–34) |
| `/contact` | Export desk form (slide 27) |

- React + Vite

- Lucide React (icons)
